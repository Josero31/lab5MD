3. Comparación con Regresión Lineal y Árbol de Regresión

Para comparar los tres modelos de forma justa, se re-entrena la regresión lineal y el árbol de regresión con el mismo split (set.seed(42), 70/30) y se evalúa sobre el mismo conjunto de prueba usando RMSE, MAE y R². Para Naive Bayes, se convierte la categoría predicha a un valor numérico usando el punto medio de cada rango, permitiendo calcular las mismas métricas de regresión.

library(rpart)

# Dataset con el mismo split pero usando price continuo
train_reg <- train %>% select(all_of(c(vars_modelo, "price"))) %>% na.omit()
test_reg  <- test  %>% select(all_of(c(vars_modelo, "price"))) %>% na.omit()

# ── Regresión Lineal ──────────────────────────────────────────────────────────
modelo_lm <- lm(price ~ ., data = train_reg)

pred_lm  <- predict(modelo_lm, newdata = test_reg)
rmse_lm  <- sqrt(mean((test_reg$price - pred_lm)^2))
mae_lm   <- mean(abs(test_reg$price - pred_lm))
r2_lm    <- cor(test_reg$price, pred_lm)^2

# ── Árbol de Regresión ───────────────────────────────────────────────────────
modelo_tree <- rpart(price ~ ., data = train_reg, method = "anova")

pred_tree <- predict(modelo_tree, newdata = test_reg)
rmse_tree <- sqrt(mean((test_reg$price - pred_tree)^2))
mae_tree  <- mean(abs(test_reg$price - pred_tree))
r2_tree   <- cor(test_reg$price, pred_tree)^2

# ── Naive Bayes → aproximar precio continuo con punto medio del rango ────────
puntos_medio <- c(

Conclusiones del análisis de la matriz de confusión:

  • Efectividad general: El modelo clasifica correctamente el 57.2% de los alquileres. Considerando que son 3 clases, superar el 33% de acierto aleatorio con un Kappa positivo indica que el modelo aprende patrones reales.

  • Donde se equivocó más: La clase Media es la más difícil de clasificar porque sus atributos (precio, habitaciones, valoración) se solapan con ambos extremos. Es el error más frecuente en cualquier modelo que prediga categorías ordinales.

  • Donde se equivocó menos: La clase Cara suele tener mayor precision porque las propiedades de lujo tienen características más diferenciadas (mayor número de habitaciones, mejores reseñas, ubicaciones premium).

  • Importancia de los errores: Los errores entre clases no adyacentes (Barata ↔︎ Cara) son los más graves desde el punto de vista de negocio, ya que implican una estimación muy alejada de la realidad. Los errores entre clases adyacentes (Barata ↔︎ Media, Media ↔︎ Cara) son tolerables porque el modelo al menos ubica la propiedad en un rango cercano al correcto. Naive Bayes, al asumir independencia entre variables, tiende a cometer más errores de tipo adyacente que de tipo extremo, lo que lo hace relativamente seguro para este caso de uso.
